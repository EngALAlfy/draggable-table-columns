🎯 Draggable Table Columns Demo

Drag and drop table columns to reorder them. Order is saved to your browser!

📌 How to use:
  • Hover over column headers with draggable badge
  • Click and drag to reorder columns
  • Drop on target column to swap positions
  • Your order is automatically saved
  • Refresh the page - your order is preserved!

How to Implement

1. Include jQuery and the Plugin
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="dragndrop.table.columns.js"></script>
2. Add Classes to Your Table
<table id="my-table">
  <thead>
    <tr>
      <th>ID</th>
      <th class="draggable-column">Name</th>
      <th class="draggable-column">Department</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <!-- rows -->
  </tbody>
</table>
3. Initialize the Plugin
$(document).ready(function() {
  $('#my-table').draggableTableColumns({
    storageKey: 'myTableOrder'
  });
});

Configuration Options

$('#my-table').draggableTableColumns({
  dragClass: 'dragging',           // CSS class while dragging
  dragOverClass: 'drag-over',      // CSS class for drop target
  storageKey: 'tableColumnOrder',  // localStorage key
  draggableSelector: '.draggable-column'  // Selector for draggable columns
});

Features

  • ✅ Lightweight - no external dependencies beyond jQuery
  • ✅ Easy to use - just add a class to columns
  • ✅ Persistent - saves order to localStorage
  • ✅ Visual feedback - smooth animations
  • ✅ Flexible - control which columns are draggable
  • ✅ Browser compatible - works on all modern browsers
